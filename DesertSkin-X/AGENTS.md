## Development commands

The MVP includes all six roadmap slices and verification notes. Use Python 3.12 and run these
commands inside a project virtual environment. Supply the actual workbook path
locally. Test workbooks are generated by pytest and are not the supplied demo.

```powershell
python -m pip install -r requirements-dev.txt
$env:DESERTSKIN_WORKBOOK = '<absolute path to the supplied workbook>'
python -m pytest -q
python -m ruff check app.py workbook.py metrics.py models.py charts.py materials_view.py run_demo.py tests
python -m ruff format --check app.py workbook.py metrics.py models.py charts.py materials_view.py run_demo.py tests
python -m mypy
python -m streamlit run app.py --server.address 127.0.0.1
```

For the packaged demo, `python run_demo.py` uses the bundled workbook or an
operator-configured path. See README.md for setup and RELEASE.md for the exact
verification boundary. Only install-time network access is needed; keep external
data services and device control out of this release.
